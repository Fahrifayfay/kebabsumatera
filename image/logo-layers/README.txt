Buka preview.html untuk melihat contoh komposisi, animasi, dan toggle layer.
PNG memiliki kanal alpha asli. Ukuran canvas dan padding tiap PNG berbeda.
layers.json berisi visibleBounds, placement pada stage 1290x1220, zIndex,
dan transformOrigin. Preview memakai viewport SVG agar padding transparan
bukan pusat animasi. Nilai placement adalah panduan susun ulang, dapat diubah.

After Effects/CapCut: impor tiap PNG sebagai layer terpisah; sesuaikan scale,
position, dan anchor point. Animasi kepala di pangkal leher; kebab di ujung
tangan; menara di pangkal penyangga. Jangan menambahkan latar hitam.

Sumber berupa PNG datar, bukan file berlayer. Aset dipisahkan/direkonstruksi
dengan built-in image_gen; bagian yang tertutup dibuat ulang dan dapat
memiliki perbedaan detail dari sumber. Bukan ekstraksi identik per piksel.
Prompt lengkap: prompts.json. Tidak mengubah logo pada website utama.
